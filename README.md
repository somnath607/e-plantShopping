# Paradise Nursery - Online Plant Shop

Paradise Nursery is a dynamic React-based e-commerce web application for browsing and purchasing houseplants online. Built with React and Redux Toolkit, it provides a seamless and interactive shopping experience.

## Features
- **Landing Page**: Features a stunning plant background, company name, introduction, and a "Get Started" button.
- **Product Catalog**: Organizes houseplants into multiple categories with at least six unique plants per category, complete with thumbnails, names, descriptions, and prices.
- **Interactive Shopping Cart**: Add items, update quantities (increment/decrement), remove items, and calculate total costs dynamically.
- **Redux State Management**: Scalable cart state management using Redux Toolkit.
- **Responsive Navigation**: Navbar on both the Product Listing and Cart pages with links to Home, Plants, and Cart, plus a live cart item count icon.

## Technologies Used
- React.js
- Redux Toolkit
- CSS3
- Vite
